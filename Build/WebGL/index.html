🎰 Slot Game - WebGL Build

This is a placeholder WebGL build folder.

To generate the actual WebGL build:

  1. Open project in Unity 2022.3 LTS
  2. File > Build Settings > Select WebGL > Switch Platform
  3. Click Build and choose Build/WebGL
  4. Commit the generated files (Build folder, wasm, js, data)
